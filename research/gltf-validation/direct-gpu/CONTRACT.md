# Direct GPU model contract

The backend source is `engine/Sandbox.Engine/Resources/Model/Gltf/DirectGpu/` (`Sandbox.Gltf.DirectGpu`). The managed glTF path uses GPU-buffer instances and `SceneCustomObject`; existing vmdl retains its native branch. Public `Model.Load` integration and remaining acceptance gates are described in [Model.Load integration](MODEL_LOAD_INTEGRATION.md). Source changes and historical receipts do not prove what is currently installed or validated; see [feature status](../FEATURE_STATUS.md) and [execution evidence](EXECUTION.md).

## Asset and instance

`GltfGpuAsset.Prepare(document, computeShaderPath, materialResolver, finalRelease, sceneIndex, allowUnselected)` prepares CPU metadata and serialized textures without GPU or native material realization. `Create` provides a shorthand. Inspect the current signatures in source before use. The caller owns the document unless successful preparation transfers its final release through the callback. `CreateInstance(world)` lazily realizes shared resources and creates per-instance state in the authored rest pose. `Placement` and `SetPose` publish revisions; computation runs in a graphics context before drawing, and draw callbacks do not advance animation time. Explicit resolver materials are borrowed; `GetMaterials()` returns a lazy immutable ordered view.

Preparation selects the requested or default scene, retaining separate node instances while sharing identical primitive inputs and immutable rigs. An unselected resource and an empty selected scene can be valid; a default-scene rendering request without a default reports an error. Primitives without `POSITION` remain in source but are skipped for drawing. `MeshCount` counts selected drawable primitive instances; `RestBounds` has no culling padding. Authored material slots are ordered by index with the implicit default last, and runtime deduplication does not merge them. Public `Model.Load(path, sceneIndex)` uses a distinct scene identity; attempting to render an unselected resource reports the missing selection.

An instance owns its scene object, output, pose, palette, weights, placement and overrides; shared assets own immutable input and material resources. Asset disposal refuses new instances but existing instances retain their generation until disposal. Final release runs once in the captured engine context. Instance disposal detaches callbacks before freeing buffers; repeated disposal is safe, active-callback disposal is deferred, and cleanup attempts all resources while retaining the original acquisition error. Test failure rollback, independent instances, repeated load/unload and empty/positive/deletion controls. Partial GPU-upload failure rollback is not yet guaranteed.

## Geometry and rendering

Input descriptors derive from materialized glTF accessor and bufferView data, including component type, normalization, offsets, stride, sparse/implicit-zero or codec handling, and all joint/weight sets. Packed input storage preserves its bytes and includes explicit arena offsets; do not assume a `GltfVertex` layout or truncate influences. Output fields and stride come from a runtime declaration; conversion is an explicit GPU operation.

One pose revision supplies full-affine node/joint matrices and signed, unclamped morph weights. Apply morphs in glTF local space before skin/node transforms and basis conversion. Convert meters to inches and `(x,y,z)` to `(z,x,y)` once; skinning ignores the skinned mesh node transform, and normals use the inverse transpose of the weighted affine transform. Placement does not round-trip through TRS and is applied once; the custom scene object's transform stays identity. Validate pose, placement and finite bounds before publishing a revision.

The path owns C# GPU buffers, uses explicit compute-write-to-vertex-read barriers, runtime vertex declarations and raw submission. It must construct no native `Model`, `Mesh`, `IModel`, model builder or native morph controller, including placeholders. Native camera, light, presentation, stock material/shader and drawing services are allowed.

Stock glTF materials are acquired through cache leases, using serialized texture generation retained during CPU preparation. Diagnostic materials and `.vmat` overrides must be identified in receipts and cannot establish source-material fidelity. Override precedence must follow measured native behavior; attribute binding alone does not prove material or sampler pixels.

## Readback and evidence

`Readback()` requires a completed successful submission. Rows identify node, optional instance, mesh and primitive; vertex fields, stride and bytes; source mode, submitted topology, draw counts and revision; source-vertex mapping and indices. Positions and normals are in engine world coordinates. `SourceVertices` is CPU provenance mapping expanded corners to source vertices, not GPU map readback. Visible rows' `Indices` come from the bound GPU buffer and identify `gpu-readback`; submission counters are CPU diagnostics, not proof of raster visibility. Earlier triangle receipts predating bound-index readback do not prove it.

Compile helpers against actual loaded producers, never replacement backend source; helper classes exposing internal types are internal with public reflection-callable entries. Model owners use independent oracles and execute their own guarded tests and captures as described in [worker context](WORKER_CONTEXT.md) and [execution coordination](EXECUTION.md). GPU readback, rendered comparison, wall-clock playback and public API behavior are separate gates.
