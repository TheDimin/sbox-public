# MorphPrimitivesTest direct GPU acceptance

## Current focused public acceptance (6 November 2026)

`public-request.json` selects three new public tests only: original `glTF` source, one canonical derived `.glb_c`, and explicitly derived source controls for node default override, absent weights and signed LINEAR animation. The old six-form 105-case inventory below remains historical preparation, not current execution proof. The original source files are unchanged. Public cases use actual `Model.Load` and `SkinnedModelRenderer`, named installed shaders and original red/green textured materials; they create no native Model/Mesh placeholders.

The canonical compiled package currently retains the external JPEG dependency, which is explicitly mounted; self-contained compiled-only packaging is not claimed. The sample authors POSITION-only targets, normals and UVs, with no animation, tangent stream or target NORMAL/TANGENT deltas. Optional target normal/tangent omission is checked by preserved normal and valid generated tangent basis; delta semantics for those streams require other fixtures. Deterministic scene-time fading and derived clip seeks do not establish wall-clock playback or performance.

## Historical prepared matrix

The source checkout is pinned to `90d7ede14c7e280af263824604b427a1ca02cb66`.
Actual upstream forms are `glTF`, `glTF-Binary`, and required `KHR_draco_mesh_compression` `glTF-Draco`; each also has an explicitly derived compiled GLB form. There is no upstream animated or nonindexed form.

The model has one default scene, root node 0, mesh node 1, one mesh and **two** indexed triangle primitives. Primitive 0 has 21 vertices, 72 ushort indices and red material 0. Primitive 1 has 9 vertices, 24 ushort indices and green material 1. Both have FLOAT POSITION/NORMAL/TEXCOORD_0 streams with different source view origins and attribute property ordering. Each primitive has its own one-target POSITION-only delta accessor. Mesh weight `[0.5]` applies without a node override; both primitives must elevate at half strength. Explicit base normals and UVs retain their values because their morph deltas are omitted. The shared base-color JPEG, linear/repeat sampler and distinct red/green factors are checked separately.

Normative baseline: [published glTF 2.0.1 morph targets](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html#_morph_targets). Its target identity/count, omitted-attribute, mesh/node default and morph-before-transform rules inform the tests. Local matrices must remain TRS-decomposable: the inherited-affine control uses valid parent nonuniform scale and child rotation. No tolerance is widened to accept invalid source or a failed result.

`../../../../../engine/Tools/Gltf/direct-gpu/models/MorphPrimitivesTest/author_reference.py` independently reads source JSON/BIN/GLB. Draco base geometry and each primitive's own triangle point order come from `../../../../../engine/Tools/Gltf/direct-gpu/models/MorphPrimitivesTest/author_draco_reference.cjs`, a separate integration of the existing pinned official Google Draco 1.5.7 WASM files. This shares codec ancestry with production Draco, and that limitation stays explicit. Morph target raw accessors remain independently read from the Draco variant's ordinary buffer views; no core-to-Draco vertex mapping is assumed. `reference.json` and `draco-reference.json` are test inputs, never producer upload data. The model is CC BY 4.0 by ft-lab; the pinned corpus retains upstream `LICENSE.md`.

Prepared runner inventory is **105 cases**: 55 core CPU/data, 5 derived layout controls, 19 pure staging, 6 source material metadata, 13 synthetic GPU checker controls and 7 synthetic image checker controls. The six Python oracle-author controls passed locally. C# cases are unrun until a coordinator receipt establishes loaded producer identity and results. The first 79-case freeze was superseded **without execution** after a local-shear fixture defect was found during review; the corrected fixture uses valid TRS hierarchy. The following 103-case freeze was also superseded without execution to adapt GPU helper accessibility to the canonical producer's internal types and add the two derived-layout checker controls.

Derived controls are labeled as such: signed node weights `-0.75` and `1.5`, omitted weights, three-key signed animation, sparse zero-base target 0, padded offset-4/stride-20 target 1, normalized SHORT POSITION/BYTE NORMAL/UBYTE UV on primitive 1, and indexed primitive 0 beside nonindexed primitive 1. Invalid controls require rejection for unequal target counts, wrong primitive-local delta vertex count, wrong node weight count and a morph semantic without its corresponding base semantic. These expand API coverage; they do not invent upstream variants.

`MorphPrimitivesGpuProbe.Run` returns 8 diagnostic rows per form: 7 numeric readback groups and one explicit pending-gates row. The `glTF` source and compiled forms each add one derived mixed-layout readback group (9 rows each), for **44 numeric readback groups** overall, including six actual authored default poses. Its signed animation is derived and proves no wall-clock playback behavior. Every readback requires both primitive identities, actual bound GPU index bytes, exact primitive-local topology/map, runtime declarations, independent positions, preserved normals/UV/default color, finite unit orthogonal tangents and valid signed tangent basis values. Source tangent direction/sign is not uniquely asserted because the source has neither authored tangents nor a normal texture. Position threshold is 0.0002 inch; normal and tangent unit/orthogonality component thresholds are 0.00002; untouched FLOAT UV and default color require exact values. The derived normalized-byte UV has a 0.00000012 component tolerance (one Float32 arithmetic-rounding allowance), and the source form's exact FLOAT UV gate is retained.

Native images remain separate gates. `MorphPrimitivesReferenceScene` uses independent raw-source triangles via `Graphics.Draw`, borrowed source/diagnostic materials and no native Model/Mesh. The coordinator must use matched camera, dimensions, projection, placement, light and material scope; collect empty-before, positive independent reference, empty-after-reference, positive actual and deleted-empty-after; and retain all capture identities/hashes. `MorphPrimitivesImageChecks.AssertMatched` requires global IoU >= 0.995, mean RGB error <= 1 byte and max <= 8 bytes, plus disjoint positive witness regions for **both** primitives. An empty expected image or an omitted green quadrant fails. `AssertDefaultMorphSensitivity` also requires independently rendered flat/half-weight references to differ at >= 16 pixels by > 8 RGB bytes so the selected view can expose an ignored default morph. Compare a deliberately wrong flat reference against the default pose and require rejection. A diagnostic-material pass does not establish stock source-material fidelity; using the same adapter for expected/actual requires the separate material feature audit.

Only `/root/gpu_validation` builds, stages, restarts, compiles shaders, drives the verified editor and captures. These model helpers do not construct native Model, Mesh, IModel, ModelBuilder or morph controllers. They consume the canonical producer; a copied research backend is not compiled into the helper. GPU, independent images, source material fidelity, public `Model.Load`, Windows and performance/compiled-vmdl benchmarks remain pending until their own receipts pass.
