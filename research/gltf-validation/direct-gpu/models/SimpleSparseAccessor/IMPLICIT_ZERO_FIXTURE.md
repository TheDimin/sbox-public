# Separate implicit-zero GPU fixture

This synthetic control is not the upstream SimpleSparseAccessor model. The inspected MorphPrimitivesLayoutFixture independently checks a zero-base sparse *morph target* in CPU materialization and a separate padded/normalized layout; it does not prove public base POSITION GPU drawing. This fixture covers that gap without repeating its CPU oracle.

The POSITION accessor has no bufferView and therefore starts as three zero vectors. Two sparse replacements, with strictly increasing UBYTE indices, select vertices (1,2) or (0,2), so different untouched vertices must remain zero. The resulting literal triangle uses vertices (0,0,0), (2,0,0), (0,2,0), cyclically reordered in the second case. Sparse index view begins at byte 16 with local offset 1; sparse values view begins at byte 24 with local offset 4 and packed 12-byte float VEC3 values. glTF sparse views do not support arbitrary byteStride; the separate UV view begins at 52, has accessor offset 4 and explicit stride 12, with padding sentinels. Indexed controls use view offset 4 and local offset 2; nonindexed controls omit primitive indices. Index order remains ascending within each sparse accessor as required by glTF.

Eight rows combine two replacement patterns, indexed/nonindexed, source/canonical compiled. Each must return a valid public managed model, exact independent GPU-read positions and strided UVs, actual bound GPU index mapping, a visible triangle and empty/deletion controls. A live bound-index collapse must be reflected in GPU readback and remove the triangle, then the original indices are restored. This negative checks raster sensitivity; it is not a separate independent image-shape oracle. No upstream image or website review is changed.
