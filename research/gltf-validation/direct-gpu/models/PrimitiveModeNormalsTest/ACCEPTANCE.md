## Normals and topology semantics

Published [glTF 2.0.1, pinned registry specification](https://github.com/KhronosGroup/glTF/blob/8e798b02d254cea97659a333cfcb20875b62bdd4/specification/2.0/Specification.adoc#meshes) requires triangle flat normals when NORMAL is missing. Four sphere meshes and the label plane need independently derived per-triangle normals. Sphere triangle cross products are nonzero and outward; no degenerate normal directions are assigned arbitrary expectations. Twelve sphere primitives have authored nearly unit normals, including points and lines. All defined normals are compared after the full inverse transpose and basis permutation. Mirrored placement reverses triangle winding once. Line-strip expansion preserves every adjacent pair, has no added closure edge, and is not affected by triangle winding rules.

Missing normals on points/lines do not identify a unique surface direction. Eight primitive instances receive position/topology/color/UV checks and a finite placeholder check, with zero normal-direction assertions. The [point and line material conventions](https://github.com/KhronosGroup/glTF/blob/8e798b02d254cea97659a333cfcb20875b62bdd4/specification/2.0/Specification.adoc#point-and-line-materials) recommend unlit base color times COLOR plus emissive for these primitives; authored-normal points/lines use standard lighting. These are recommendations and separate source-material fidelity gates, not invented normal-vector conformance tests. Point/line size and style are application choices; do not demand a universal screenshot/pixel width.

## Frozen callable gates

* `PrimitiveModeNormalsCoreTests.RunAll(checkoutRoot)`: 104 CPU/staging assertions, 52 in each source/derived-compiled form. Every primitive checks source descriptors, full owned source views, normalized u8 colors, source-view origins, aliased POSITION/NORMAL storage, implicit or u16 indices, independently expanded topology, runtime declarations and raw arena bytes. Label image and material inputs are preserved.
* `PrimitiveModeNormalsGpuVerifierTests.RunAll(checkoutRoot)`: 13 synthetic checker controls. Four valid arbitrary output-field layouts; eight corrupted position, authored/generated normal, triangle winding, color, UV, source mapping and line adjacency cases must fail; changing an unspecified point normal direction must pass. These are CPU checker tests, never actual GPU evidence.
* `PrimitiveModeNormalsGpuProbe.Run(checkoutRoot, world, computeMaterial, waitForActualFrames, diagnosticMaterialResolver = null, requireSubmittedModeEvidence = false)`: eight completed-GPU measurements (four placements in each form), each containing all 25 primitive rows. This validates actual vertex and bound-index-buffer readback, source mapping and winding, generated/authored normals, colors and UVs. Tests cover rest, full affine shear, mirrored affine and restored rest. It creates no native Model/Mesh. The coordinator supplies real submitted frames, compiled shader/material and guard admission. `requireSubmittedModeEvidence: true` additionally enforces the additive submitted-mode gate and records its scope; false cannot claim mode acceptance.

Numeric thresholds are enforced: maximum position component error .002 engine inches, defined normal component error .00005, normalized color component error .000001, exact UVs and exact topology. Float basis conversion and affine multiplication differ by normal GPU rounding; thresholds remain explicit, frozen before execution, and must not be increased to hide a failure. The checker deliberately derives runtime field offsets/stride instead of using `GltfVertex` or stock `Vertex` packing. Source-versus-compiled agreement is never its oracle.

## Evidence and remaining gates

`source-audit.json` records the executed lightweight Python audit only. No C# tests, GPU readback or images are claimed from preparing these files. The worker never builds, launches/drives an editor, compiles shaders or mutates shared source. The coordinator owns execution and receipts.

Actual raw point/line/triangle draw acceptance additionally requires per-primitive submitted topology evidence or a graphics capture, plus matched empty-before, positive and deleted-empty controls. Aggregate DrawCalls alone does not prove a particular draw's mode. `PrimitiveModeNormalsGpuChecks.RequireSubmittedModes(rows, revision)` is a separate reflection-based gate for the backend owner's agreed additive SourceMode/SubmittedPrimitiveType/SubmittedRevision/DrawCalls fields; it deliberately fails as pending when these do not exist. The submission diagnostic records the actual DrawIndexed argument after successful return, not a GPU rasterizer topology query. Preserve this gate as pending until independently observed. Never substitute quads or triangle ribbons and call that a point/line draw pass.

`PrimitiveModeNormalsReferenceScene(reference, world, placement, materialForPrimitiveContext, selectedMeshes = null, deliberatelyWrongPrimitiveTypes = false)` supplies independent literal geometry through native Points, Lines and Triangles with bounded chunks, without Model/Mesh allocation. Optional explicit mesh selection is for cell or mode captures; it never excludes other primitives from the inventory. The deliberate wrong-mode flag is a sensitivity control that must visibly differ in a suitable camera/material setup. The coordinator must retain all capture controls and reviewed thresholds. Use a normal-independent diagnostic for missing-normal point/line cells; their placeholder normal direction is not an image conformance oracle. The opaque diagnostic label plane can obscure silhouette evidence for spheres behind its screen area, so a blanket foreground count is insufficient: establish visible controls for each point/line/triangle group and the label plane using documented camera/material/depth conditions.

Rendered source-material parity is pending: compare a matched independent reference using the same input data and actual corresponding native primitive modes, with declared camera, dimensions, placement, material/light/exposure and explicit thresholds. The upstream screenshot has no matched capture contract and cannot serve as a pixel oracle. Diagnostic overrides establish geometry only. A common stock material indexed only by source material is insufficient evidence for the recommended distinct lit/unlit behavior when points/lines with and without NORMAL share that material. This was reported to the shared backend owner. Empty and deleted-empty controls, lifecycle/instance isolation, public Model.Load and Windows coverage remain separate shared or integration gates; this static sample has no animation cadence claim.
